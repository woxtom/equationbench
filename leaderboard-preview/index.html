03 / The metric

Why a weighted score?

A raw average lets easy arithmetic hide failures on frontier tasks. EquationBench weights every correct answer by its difficulty level (1–5), then normalizes by the available weight:

EQB Score = 100 · Σ (level · correct) / Σ level
ExactInteger, rational, or integer vector after canonicalization. No tolerance.
Closed-bookTools and code execution are disabled for every model.
PairedAll models answer the same fixed task set; CIs resample tasks, not prompts.

05 / Protocol

Built to be cited, not gamed.

EquationBench is deterministic from a master seed, exactly verifiable, and versioned end to end.

01Procedural

Every task is generated by a program from a seed. The public set is reproducible; the sealed holdout is encrypted.

02Exact

Ground truth is computed with integer and rational arithmetic. There are no LLM judges and no tolerance bands.

03Auditable

Runs store prompts, responses, token usage, cost, latency, and the dataset hash. Every leaderboard row links to one.

04Uncertainty-aware

Reported intervals are paired cell-cluster bootstrap estimates over the benchmark tasks.

06 / Contamination

The test set is public. The holdout is not.

The open leaderboard uses a fixed public test set so anyone can reproduce a result. A separate sealed holdout—encrypted at rest, with a published hash commitment—is used to validate top entries and future seasons.

Run your model. Publish the receipt.
