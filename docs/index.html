EquationBench Linear

How large a dense integer linear system can a language model solve exactly? Every task is a system A·x = b with a unique integer solution. The model gets one prompt, no tools, and must return the exact vector. The score is the system size where a model drops to a 50% success rate.

How to read it

  • EQB-L is the 50% frontier, in continuous ladder levels. Level L is a system of size round(3·2(L−1)/3). Level 10 is 24×24, level 11 is 30×30.
  • EQB-C is the rank key: EQB-L × Band. Band is the exact-solve rate over the levels in [EQB-L − 2, EQB-L + 1].
  • Solved counts exact answers over all tasks. Cover counts valid answers over all tasks. Timeouts and provider errors lower cover, not the solve rate.
  • Bounds such as ≥ 8.0 are not measurements. Those rows are unranked. † marks a level with fewer than 3 valid tasks.
  • Official rows use a direct provider at max effort. Everything else is provisional.
Unofficial. Not peer-reviewed. One measurement, not a general math score. Tasks are regenerated from a published seed, so every row can be re-run.
